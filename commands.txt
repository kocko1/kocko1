CAPRI — COMMANDS AND CONTROLS
Updated 2026-10-30

Type commands in Capri's floating chat and press Enter.
<words in brackets> are placeholders: replace them with your own text.
Local desktop commands work independently of the selected AI model.

CODING — EVERY CONNECTED PROVIDER
--------------------------------
select project                  Choose an existing folder using a folder picker.
project C:\Projects\MyApp       Select a folder by path (quotes around spaces allowed).
code <task>                     Run one coding task with the currently selected model.
code: <task>                    Same as code <task>.
coding task <task>              Same as code <task>.
coding on                      Route ordinary chat requests to coding tools.
coding off                     Stop the task and return to ordinary conversation.
coding status                  Show mode, project folder, and working/idle status.
coding activity                Open the action/output window.
approve command                Approve the exact terminal command shown there.
reject command                 Decline the proposed terminal command.
coding undo                    Undo the latest checkpoint of Capri's file edits.
stop                           Cancel model/tool work; completed edits remain.

Example:
  select project
  use codex
  code Add a dark mode toggle, preserve the existing design, and run the tests.

You can choose any connected provider: Codex, OpenAI API, Claude API,
Gemini API, local, Antigravity, or Claude Desktop. The selected model decides
which tools to request. Capability and structured-output reliability vary by model.

Tools available to the model:
  list files, read UTF-8 text, create new text files, replace exact text blocks,
  propose PowerShell commands, and open a text file in the editor.
Capri edits actual project files, then opens them in VS Code if installed,
otherwise Notepad. This is file-based editing, not simulated typing into an
arbitrary app or unsaved editor buffer. Save your editor drafts before a task.
Existing local commands still take priority in coding mode. Use code <task>
when a coding request begins with a local command such as open or run.

The project selection is remembered; coding mode starts off after restart.
The activity window shows actions, file content/tool output, errors, and
terminal approval requests. Its Stop, Approve command, and Reject command
buttons are equivalent to their chat commands. Closing it does not stop work.

File tools stay inside the chosen folder, refuse linked paths and credential
files such as .env, and refuse edits if the file changed since it was read.
Files are UTF-8 text, up to 200 KB for reading, with bounded model context.
Large tasks may need several smaller requests. Each task has a 30-step limit.
Antigravity's desktop command transport has a smaller context limit than APIs.

Terminal commands run with your Windows account in the chosen folder.
The exact command requires approval each time, expires after five minutes,
and has a two-minute execution limit. Commands are NOT confined to the folder.
Stop terminates the command process and its children; earlier effects remain.
Remote model requests may take time to finish stopping, but late replies
cannot start another tool action in the cancelled task.

Undo restores checkpointed file edits only. It refuses to overwrite manual
changes made afterward. It does NOT undo terminal command effects, new empty
folders, installs, publishing, or external actions. Backups are kept under:
  %LOCALAPPDATA%\CapriEdgerunnerWidget\coding\checkpoints
Project file contents needed for a task go to the selected AI provider.
Live provider coding has not been verified against every model; local tool
and mocked-provider tests cover editing, undo, cancellation, and approval.

CLAUDE DESKTOP RETRIES: Capri verifies prompt insertion before sending and never falls back to foreground typing. Retrying the identical task may reuse its exact unsent prompt. A different draft is preserved; clear or send that draft yourself before retrying.

CLAUDE DRAFT RECOVERY: Capri now records hashes of prompts it inserts, so its own leftover drafts can be replaced on the next coding step or retry. User-written or modified drafts remain protected. New-chat resets finish before the next Claude request begins. All operations remain in the background. Drafts from older builds cannot be automatically identified.

CLAUDE BACKGROUND RECOVERY
If Claude works visible but Send stalls in the background: fully Quit Claude from its system tray (closing its window is not enough), then type use claude in Capri. Capri starts it with background rendering/timer options. These options only apply to a new Claude process. Retry your message while another app is active. Capri does not activate Claude to send. If it still fails, the local claude-insertion-diagnostic.txt now includes Send/voice control readiness without saving your prompt text.

UNINSTALL APPS

uninstall <app name> - same command.
yes - uninstall the exact confirmed app; confirmation expires after 2 minutes.
no / cancel - cancel removal. Other input clears the pending confirmation.

OPTIONAL VOICE
voice on - enable spoken replies using your local F5-TTS and capri_clean.mp3. This saved setting also warms up the voice engine automatically when Capri starts. First loading can take several minutes.
voice off - disable spoken replies and stop playback.
voice stop - stop current/queued speech, leaving future spoken replies enabled.
voice input on - enable the saved global push-to-talk key (default V).
voice input off - disable recording and release the global key.
voice key F8 - change and save the push-to-talk key. Supports A-Z or F1-F12. Example: voice key V. Alias: voice keybind F8.
voice status - show voice output, microphone input and selected key.
Hold the microphone key while talking; release it to automatically send the recognized text. A recording is limited to 30 seconds. No always-listening microphone. Recognition uses local Whisper transcription. Select your input device in Voice & Microphone Settings. Use an empty chat draft; Capri will not overwrite or automatically send existing typed text.
The chosen unmodified key is reserved globally while voice input is enabled, including while typing. Ctrl+V remains available. F8 is useful if you need to type V normally.
Voice enable switches and the keybind persist after restart. Text chat still works if F5-TTS is unavailable. Destructive commands retain their usual confirmation.
Test: voice on; voice key F8; voice input on; hold F8, say hello, release F8. The message should send and Capri should speak its reply.
VOICE SETTINGS WINDOW
Open Capri Settings and choose VOICE & MICROPHONE SETTINGS. Change spoken replies, automatic F5-TTS startup, microphone enablement, and the hold-to-talk key; click Save. Automatic voice-engine startup now defaults on independently of spoken replies.
Test microphone records for five seconds and displays recognized words without sending. If no words are recognized, it reports whether microphone audio was detected. Choose Windows default, Sonar, headset, or laptop microphone. Recording ends on key release; local transcription then automatically sends the recognized message.

VOICE SETTINGS UPDATE
Voice Settings uses Capri styling, stays above Capri, and can be moved by dragging its header. Choose Local F5-TTS or ElevenLabs. ElevenLabs API key is masked and stored with Windows user encryption; the voice ID is editable. F5-TTS uses your capri_api.py defaults and reference audio without replacing your scripts. The microphone test records for five seconds, then transcribes locally. First use can take longer while the speech model loads. It never sends the test transcript.
ElevenLabs sends reply text to ElevenLabs when selected; account credits apply. The configured key currently lacks voices_read, so voice-detail lookup cannot verify it; speech permission is separate.

DESKTOP-ONLY IDLE FACE
When an app covers Capri in desktop-only mode, the supplied face image stays above apps instead of disappearing completely. Drag the face to position it; its position is saved separately. Click it to open Capri chat. The full character returns when her desktop position is uncovered. Over-apps mode keeps the normal character.
Main Settings and Voice Settings are non-modal: you can move Capri while either is open. Drag each settings header to move its window. Sprite position lock still applies if enabled.

Idle face keeps its green eye panel and transparent exterior, with a gentle floating and tilting animation. Drag it to position it; its position is saved.

Microphone transcription uses the cached Whisper base model on CPU independently of F5-TTS and ElevenLabs. Voice output does not need to be enabled for microphone input.

Voice & Microphone Settings: choose Microphone / Input Device and Speaker / Output Device, then Save. These affect Capri only; Windows defaults remain unchanged. Output selection applies to both F5-TTS and ElevenLabs replies.
Speech to Text: choose Local Whisper or ElevenLabs. ElevenLabs uses the same encrypted API key, sends microphone recordings to its Scribe v2 service and uses account credits; no voice ID is needed for transcription. Test microphone uses the selected input/provider/key without sending the transcript to chat. Save to apply to hold-to-talk. Release the configured key to transcribe and send.
Quit Capri Widget closes the main window and stops voice playback/recording without the Application.Exit collection error.
Voice Settings opens immediately and discovers input/output devices in the background. Saved devices remain selectable while discovery runs. Close and reopen settings to refresh after plugging in a new device.

Voice Settings has separate TEXT TO SPEECH MODEL and SPEECH TO TEXT MODEL selectors. ElevenLabs output: Multilingual v2, Flash v2.5, v3, v4, v4 Turbo (account access required). ElevenLabs transcription: Scribe v2 or Scribe v1. Local transcription: Whisper tiny, base or small; a selected missing local model downloads on first use. F5 uses its installed model. Voice ID is separate from model.
Microphone inputs include MME and WASAPI devices. If the headset MME input is silent, select Microphone (Arctis Nova Pro) [WASAPI]. Test microphone counts five seconds after the device is ready. PROFILE, MOODS & REMINDERS
Open Capri Settings > PROFILE, MOODS & REMINDERS, or type companion settings / profile settings.
Set your preferred name and describe how Capri should perceive and address you. These tone preferences apply to normal conversation across providers.
Dynamic moods: on by default, adjustable gaming limit (default 90 active minutes). Capri becomes mildly frustrated at the limit and more exasperated at twice the limit. She sends one notice per stage. Ten minutes away from the configured games resets the session and mood. Configure exact process names without .exe, separated by commas. Only foreground game time counts; this does not close games or change their settings.
Lightning visual alerts: toggle in companion settings. A brief cyan lightning/border fade appears over each monitor, without taking focus or blocking clicks. No repeated strobing.
Reminder commands:
  remind me in 20 minutes to stretch
  remind me in 2 hours to check dinner
  remind me at 18:30 to take a break
  remind me at 2026-11-01 09:00 to check my calendar
  alarm at 18:30 take a break
  remind me after 90 minutes of gaming to rest
  remind me when chrome closes to stretch
  remind me when roblox closes to check homework
  reminders
  cancel reminder <id>
Times use this PC's local timezone and 24-hour clock. A time without a date means its next occurrence. App-close reminders arm once the process is observed running; they trigger when all matching processes stop. Gaming reminders count the current active session. Reminders are one-shot and persist across restarts; completed reminders are removed. Capri must be running to alert. Overdue date/time reminders trigger at next startup. No wake-from-sleep scheduling. GUI supports adding time/date reminders and removing a selected reminder. Notifications go to chat history and the Windows tray, plus lightning if enabled.

Background terminal execution: Capri launches its shell/Codex runner hidden. Coding PowerShell commands default Start-Process children to WindowStyle Hidden. AI instructions require background shell work and forbid opening interactive terminal windows unless requested. Explicit app-open requests remain visible. Coding activity no longer pops up automatically; type coding activity to open it. Command approval requests appear in chat; approve command / reject command retain the existing approval checks.

STEAM GAMES & SPOKEN NOTIFICATIONS
steam games - list local Steam library game names and IDs across library folders.
install steam <game name or ID> - open Steam's installation flow for the exact game. If a title is ambiguous, Capri lists matches; repeat with its ID. Steam handles ownership, disk space, library selection and any required prompts. No purchase is made.
delete steam <installed game name or ID> - open Steam's own uninstall dialog. uninstall steam / remove steam are aliases. No game folder or manifest is manually deleted. Steam may require its own confirmation; this does not remove the license from your account.
steam alerts on / steam alerts off - toggle completion announcements.
notification settings / steam settings / alert settings - open Steam & Spoken Notifications. Also available from main Settings.
Completion alerts monitor newly appended Steam content-log entries while Capri is running, and announce only finished installs/updates, not a paused download or merely completed network transfer. Existing historical downloads are not replayed. Checks run approximately every 8 seconds.
Notification Relay: enable Read new notifications from selected apps, tick apps, then Save. Refresh apps to update the list. Notification access requests Windows permission if needed. Only selected apps' new Windows toast notifications are read; existing notification history is not replayed and notifications are never dismissed. An app must actually send Windows notifications; private in-app-only banners are not supported. Repeated polls do not repeat the same notification. Bursts are limited to five announcements per poll.
Both alert features use Capri's selected voice provider/model and speaker. Enable Speak Capri's replies in Voice & Microphone Settings. If ElevenLabs is selected, notification text goes to that service for speech and uses its credits. Local F5 keeps speech generation local. Microphone recording suppresses spoken alerts while you talk. Notifications are voice-only: they never appear in chat or conversation history and are never executed as instructions. Voice must be enabled; notifications are silent while microphone recording is active.
Steam completion alerts default on. General notification reading defaults off until you choose apps. Both require Capri to be running.

Steam installation search now shows a numbered list in chat. Reply with the number to install, or cancel. Steam app metadata filters results to type game; DLC, texture packs, videos, demos and software are excluded. Numeric install IDs are validated as games too. Unknown/unavailable entries are not offered. Your numbered selection starts installation. Capri automatically invokes Install for the selected game when it can identify the Steam dialog. Steam uses its currently selected library and shortcut settings.


Steam chat selection expires after five minutes. Invalid numbers do not install anything. A different command cancels the old selection. Automatic install approval is scoped to a Steam window containing the selected game name, an Install button and Cancel; if the dialog cannot be identified, Capri reports that Steam needs attention. Store purchase, account login, license and Windows permission prompts are not automatically accepted. No separate Capri picker or confirmation window is opened.

FAST MICROPHONE & WAKE WORD
Microphone capture now stays ready while push-to-talk or wake-word mode is enabled. Python and the input device are initialized once instead of on every press. Changing devices restarts the microphone service; initial startup still takes a few seconds. Idle audio is discarded and never saved or uploaded.
Voice & Microphone Settings > Wake on Hey Capri (local, always listening) enables/disables wake activation. Commands: wake word on / wake word off. Wake activation uses a local Vosk small English model, independently of the selected speech-to-text provider.
Say Hey Capri, pause and wait for the recording cue/green outline, then speak the command. About 1.4 seconds of silence after speech ends recording and sends it through the selected speech-to-text provider. No speech for 8 seconds cancels; maximum recording is 30 seconds. Push-to-talk still records until key release.
Wake detection pauses while Capri is replying, playing speech, recording, or you have a typed draft. Audio before wake activation is not sent to ElevenLabs; recorded command audio uses your configured transcription provider. Turn both microphone input and wake-word mode off to release the microphone. Recognition of your pronunciation still needs a live test.

ON-DEMAND SCREEN CONTEXT
look at my screen - capture the monitor containing the mouse pointer and describe it using the selected provider.
look at screen 2 what is this error? - capture a specific monitor and ask a question. Screens are numbered from 1 in Windows enumeration order.
view screen 1 <question> / what is on my screen - alternate screen commands.
read my screen / read screen 2 - extract text locally using Windows OCR, without sending it to an AI provider or speaking the extracted text aloud.
Screen capture occurs only for an explicit screen command. A temporary screenshot is deleted after the request finishes. No continuous visual monitoring or screen history is added.
Codex, OpenAI, Anthropic, Gemini and local API connections receive the screenshot; the selected model must support image input. Claude Desktop receives the actual screenshot; it briefly comes forward to upload it, then resumes background processing. Antigravity opens the temporary screenshot with its image-capable read_file tool, providing actual image context. Non-local vision requests send the captured screen to the selected provider. Screen commands inspect the display; they do not click or execute instructions shown on it.

Wake detection requires the complete phrase Hey Capri, followed by a short pause, with high confidence for both words. Partial guesses, Capri alone, and phrases containing extra recognized words are ignored. This reduces false activations but can miss quiet or unclear speech. No voice enrollment is required; wake processing remains local.

Idle face animation uses frontal artwork with equal-sized eyes and gradually eases between a straight-on pose and an angled pose, repeating every eight seconds. The recording outline stays square and stationary. Use only clip that for the SteelSeries clip command (case-insensitive, optional final punctuation).

AI SETTINGS CHANGES IN CHAT
All AI provider routes can request validated settings changes in normal conversation. Examples: Turn off Hey Capri activation; Make the gaming timer 60 minutes; Only show yourself on the desktop; Call me Alex; Change my microphone key to F8; Stop announcing Steam downloads; Enable spoken notifications for Discord.
Supported: voice and microphone toggles, wake word, microphone key and devices, speaker, speech providers and models, ElevenLabs voice ID, gaming timer and tracked processes, profile and nickname, lightning, Steam alerts, notification app selection, visibility, size, lock/click-through, autocorrect, persona, provider/model and per-provider defaults, Codex access and automatic command approval. API keys remain in Settings and are never included in AI context.
